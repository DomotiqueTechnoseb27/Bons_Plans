# Bons Plans Domadoo

Application Mac de Domotique Technoseb27 : sélection automatique de promotions Domadoo
avec liens affiliés, prête à publier sur le blog.

Ce dépôt sert aux mises à jour automatiques de l'application : `version.json` indique la
dernière version et l'empreinte SHA-256 de chaque fichier.

Pour publier une mise à jour : remplacer `server.py`, `index.html` et `version.json`
par les nouveaux fichiers fournis (les trois ensemble).
